# Модератор Групп Telegram

## Описание

Этот Telegram бот предназначен для помощи в модерации групп. Он включает следующие функции:
- Ручное управление пользователями: бан, временный бан, мут (ограничение на отправку сообщений), снятие ограничений, выдача предупреждений.
- Автоматические действия: капча для новых участников, автоматический бан при накоплении 3-х предупреждений.
- Логирование: все важные действия модераторов и бота логируются в специальный Telegram канал.
- Интерактивные элементы: подтверждение опасных действий через инлайн-кнопки, меню модерации `/mod`.

## Настройка

### 1. Получение токена бота
- Откройте Telegram и найдите `@BotFather`.
- Отправьте команду `/newbot`.
- Следуйте инструкциям, чтобы задать имя и username для вашего бота.
- @BotFather выдаст вам токен. Скопируйте его – это ваш `BOT_TOKEN`.

### 2. Переменные окружения
Для работы бота необходимо установить следующие переменные окружения:

-   `BOT_TOKEN`: Токен вашего Telegram бота, полученный от @BotFather.
    *   **Примечание:** В файле `bot.js` используется плейсхолдер `YOUR_TELEGRAM_BOT_TOKEN`. Перед запуском замените его на реальный токен или, что предпочтительнее, установите переменную окружения `BOT_TOKEN`.
-   `LOG_CHANNEL_ID`: ID Telegram канала для логирования действий бота.
    *   **Как получить ID канала:**
        1.  Создайте публичный или частный канал.
        2.  Чтобы бот мог отправлять сообщения, он должен быть добавлен в этот канал как администратор с правом "Отправка сообщений".
        3.  **Для публичного канала:** ID канала – это его username (например, `@my_log_channel`).
        4.  **Для частного канала:**
            *   Вы можете временно сделать канал публичным, скопировать его username (который будет его ID в числовом виде с префиксом, например, `-100XXXXXXXXXX`), а затем снова сделать частным.
            *   Либо используйте ботов типа `@RawDataBot` или `@getidsbot`: перешлите любое сообщение из вашего канала этому боту, и он покажет ID канала (обычно это отрицательное число, например, `-100XXXXXXXXXX`).
    *   **Важно:** Если `LOG_CHANNEL_ID` не установлен, логирование в канал будет отключено (бот выведет предупреждение в консоль при старте).

### 3. Запуск бота
- Убедитесь, что у вас установлен Node.js и npm.
- Перейдите в директорию проекта: `cd telegram_bot_project`
- Установите зависимости: `npm install`
- Запустите бота: `node bot.js`
  (Если вы не заменили плейсхолдер токена в коде, установите переменную окружения перед запуском: `export BOT_TOKEN="ВАШ_ТОКЕН" && node bot.js` на Linux/macOS или `$env:BOT_TOKEN="ВАШ_ТОКЕН"; node bot.js` в PowerShell на Windows).

## Права Бота в Группах

Для корректной работы всех функций бот должен обладать следующими правами администратора в тех группах, где он используется:

-   **Блокировка пользователей (`can_ban_users`):** Необходимо для команд `/ban`, `/tempban`, автоматического бана за капчу и предупреждения.
-   **Ограничение пользователей (`can_restrict_members`):** Необходимо для команд `/mute`, `/unmute`.
-   **Удаление сообщений (`can_delete_messages`):** Необходимо для удаления сообщения с капчей после ее прохождения или истечения времени.
-   **Отправка сообщений:** Необходимо для всех ответов бота, сообщений капчи и т.д. (обычно включено по умолчанию).
-   **Приглашение пользователей по ссылке (`can_invite_users`):** Необязательно, но может быть полезно для некоторых аспектов управления.

## Команды Бота

Все команды модерации доступны **только администраторам чата**.

-   `/start` - Отправляет приветственное сообщение и информацию о боте.
-   `/ban <ID пользователя или ответ на сообщение>`
    -   Перманентно блокирует пользователя в чате. Требует подтверждения через инлайн-кнопку.
-   `/tempban <ID пользователя или ответ на сообщение> <минуты>`
    -   Временно блокирует пользователя на указанное количество минут. Требует подтверждения.
    -   Пример: `/tempban 123456789 60` или ответом `/tempban 60`
-   `/mute <ID пользователя или ответ на сообщение> [минуты]`
    -   Запрещает пользователю отправлять сообщения на указанное количество минут. По умолчанию – 60 минут. Требует подтверждения.
    -   Пример: `/mute 123456789 30` или ответом `/mute 30`
-   `/unmute <ID пользователя или ответ на сообщение>`
    -   Снимает ограничения на отправку сообщений с пользователя.
-   `/warn <ID пользователя или ответ на сообщение>`
    -   Выдает пользователю предупреждение. При достижении 3-х предупреждений предлагается автобан.
-   `/warns <ID пользователя или ответ на сообщение>`
    -   Показывает количество предупреждений у пользователя.
-   `/mod`
    -   Открывает инлайн-меню модерации с кнопками, которые подсказывают, как использовать основные команды.

## Автоматические Функции

-   **Капча для новых участников:**
    -   Когда новый пользователь (не бот) присоединяется к чату, ему отправляется сообщение с кнопкой "Я не бот".
    -   У пользователя есть **3 минуты (180 секунд)**, чтобы нажать на кнопку.
    -   Если пользователь не нажимает кнопку в течение этого времени, он автоматически блокируется.
    -   После успешного прохождения или истечения времени сообщение с капчей удаляется.
-   **Автобан при 3-х предупреждениях:**
    -   Когда пользователь получает третье предупреждение, бот предлагает администратору подтвердить перманентный бан этого пользователя.
    -   Администратор может подтвердить или отменить бан (в последнем случае предупреждения пользователя сбрасываются).
-   **Логирование действий:**
    -   Все действия модераторов через бота (бан, мут, предупреждения и т.д.), а также системные действия (автобан за капчу/предупреждения, прохождение капчи) логируются в указанный `LOG_CHANNEL_ID`.
    -   Формат лога: `[Дата и время] [ДЕЙСТВИЕ] Модератор: Имя (ID) Пользователь: Имя (ID) Причина/Детали: (если есть)`

## Важно

-   Убедитесь, что бот имеет необходимые права администратора в группах и в канале для логирования.
-   Все команды модерации проверяют, является ли использующий их администратором чата.
-   Бот не может применять действия к другим администраторам или к самому себе.
-   Команды модерации предназначены для использования в группах и супергруппах, а не в личных чатах с ботом.
