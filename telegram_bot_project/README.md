# Модератор Групп Telegram

## Описание

Этот Telegram бот предназначен для помощи в модерации групп. Он включает следующие функции:
- Ручное управление пользователями: бан, временный бан, мут (ограничение на отправку сообщений), снятие ограничений, выдача предупреждений, управление голосовыми сообщениями.
- Автоматические действия: капча для новых участников, автоматический бан при накоплении 3-х предупреждений, автоматическое разглушение пользователей по истечении срока.
- Логирование: все важные действия модераторов и бота логируются в специальный Telegram канал (если настроено).
- Интерактивные элементы: подтверждение опасных действий через инлайн-кнопки, меню модерации `/mod`.
- Статистика: сбор и отображение статистики по командам бота.

## Настройка

### 1. Получение токена бота
- Откройте Telegram и найдите `@BotFather`.
- Отправьте команду `/newbot`.
- Следуйте инструкциям, чтобы задать имя и username для вашего бота.
- @BotFather выдаст вам токен. Скопируйте его – это ваш `BOT_TOKEN`.

### 2. Конфигурация через `.env` файл (Рекомендуется)

Для удобства и безопасности конфигурационных данных, таких как токен бота и ID канала для логов, рекомендуется использовать `.env` файл.

1.  **Создайте файл `.env`**: Скопируйте файл `.env.example`, находящийся в корневой директории проекта (`telegram_bot_project`), и переименуйте копию в `.env`.
    ```bash
    cp .env.example .env
    ```
2.  **Заполните `.env` файл**: Откройте файл `.env` в текстовом редакторе и укажите ваши реальные значения для переменных:
    *   `BOT_TOKEN`: Ваш токен Telegram бота.
    *   `LOG_CHANNEL_ID`: ID вашего Telegram канала для логирования (числовой ID, например `-100XXXXXXXXXX`, или `@username` публичного канала). Оставьте пустым, если логирование в канал не требуется.
    *   `STATS_FILE_PATH` (опционально): Путь к файлу для хранения статистики. По умолчанию используется `bot_stats.json`.

3.  **Безопасность**: Добавьте файл `.env` в ваш `.gitignore`, чтобы случайно не загрузить его в систему контроля версий с вашими секретными данными. (Примечание: если вы не используете Git, просто убедитесь, что этот файл не публикуется).

Бот автоматически загрузит эти переменные при запуске благодаря библиотеке `dotenv`.

### 3. Переменные окружения (Альтернативный способ)

Вы также можете задавать конфигурационные переменные напрямую в окружении вашей системы. Если переменная установлена и в системном окружении, и в `.env` файле, значение из системного окружения обычно имеет приоритет.

-   `BOT_TOKEN`: Токен вашего Telegram бота. **Обязательная переменная.**
-   `LOG_CHANNEL_ID`: ID Telegram канала для логирования.
    *   **Как получить ID канала:**
        1.  Создайте публичный или частный канал.
        2.  Бот должен быть добавлен в этот канал как администратор с правом "Отправка сообщений".
        3.  **Для публичного канала:** ID канала – это его username (например, `@my_log_channel`).
        4.  **Для частного канала:** Используйте ботов типа `@RawDataBot` или `@getidsbot`: перешлите любое сообщение из вашего канала этому боту, и он покажет ID канала (обычно это отрицательное число, например, `-100XXXXXXXXXX`).
    *   **Важно:** Если `LOG_CHANNEL_ID` не установлен (ни в `.env`, ни как системная переменная), логирование в канал будет отключено (бот выведет предупреждение в консоль при старте).
-   `STATS_FILE_PATH`: Путь к файлу статистики. Если не указан, по умолчанию используется `bot_stats.json` в директории проекта.

### 4. Запуск бота
- Убедитесь, что у вас установлен Node.js и npm.
- Перейдите в директорию проекта: `cd telegram_bot_project`
- Установите зависимости (включая `dotenv`, если еще не установлено): `npm install`
- Запустите бота: `node bot.js`

## Права Бота в Группах

Для корректной работы всех функций бот должен обладать следующими правами администратора в тех группах, где он используется:

-   **Блокировка пользователей (`can_ban_users`):** Необходимо для команд `/ban`, `/tempban`, автоматического бана за капчу и предупреждения.
-   **Ограничение пользователей (`can_restrict_members`):** Необходимо для команд `/mute`, `/unmute`.
-   **Удаление сообщений (`can_delete_messages`):** Необходимо для удаления сообщения с капчей после ее прохождения или истечения времени, а также для удаления сообщений от заглушенных пользователей или пользователей с отключенными голосовыми.
-   **Отправка сообщений:** Необходимо для всех ответов бота, сообщений капчи и т.д. (обычно включено по умолчанию).

## Команды Бота

Большинство команд модерации доступны **только администраторам чата** и предназначены для использования в группах.

-   `/start` - <i>Начало работы с ботом, приветственное сообщение.</i>
-   `/help` - <i>Показать справочное сообщение со списком команд.</i>
-   `/ban &lt;ID или ответ&gt;</code> - <i>Перманентная блокировка пользователя.</i>
-   <code>/tempban &lt;ID или ответ&gt; &lt;минуты&gt;</code> - <i>Временная блокировка. Пример: <code>/tempban 123456789 60</code></i>
-   <code>/mute &lt;ID или ответ&gt; [минуты]</code> - <i>Запрет сообщений (мут). По умолчанию 60 мин. Пример: <code>/mute 123456789 30</code></i>
-   <code>/unmute &lt;ID или ответ&gt;</code> - <i>Снятие ограничений на отправку сообщений.</i>
-   <code>/warn &lt;ID или ответ&gt;</code> - <i>Выдать предупреждение. При 3-х – предложение автобана.</i>
-   <code>/warns &lt;ID или ответ&gt;</code> - <i>Посмотреть количество предупреждений.</i>
-   <code>/togglevoice &lt;ID или ответ&gt;</code> - <i>Включить/отключить пользователю отправку голосовых сообщений.</i>
-   <code>/mod</code> - <i>Интерактивное меню модерации.</i>
-   <code>/stats</code> - <i>Показать статистику работы бота (баны, муты и т.д.).</i>
-   <code>/testcaptcha</code> - <i>(Только в личных сообщениях с ботом) Проверить работу системы капчи для себя.</i>

<i>Примечание: Для команд, работающих с пользователем, вы можете либо ответить на его сообщение, либо указать его ID, либо упомянуть его через @username (если бот может его найти в данном чате).</i>

## Автоматические Функции

-   **Капча для новых участников:**
    -   При входе нового пользователя (не бота) отправляется сообщение с кнопкой "Я не бот".
    -   У пользователя **3 минуты (180 секунд)** для нажатия.
    -   При невыполнении – автоматический бан. Сообщение с капчей удаляется.
-   **Авто-размут:**
    -   Пользователи, заглушенные через `/mute`, автоматически разглушаются по истечении срока.
    -   Сообщения от заглушенных пользователей удаляются.
-   **Автобан при 3-х предупреждениях:**
    -   После 3-го предупреждения бот предлагает администратору подтвердить бан пользователя.
-   **Логирование действий:**
    -   Действия модераторов и автоматические системные действия логируются в канал, указанный в `LOG_CHANNEL_ID`.
-   **Автоудаление информационных сообщений бота:**
    -   Многие подтверждающие сообщения от бота (например, "Пользователь X был заглушен") автоматически удаляются через 3 минуты.

## Важно

-   Убедитесь, что бот имеет необходимые права администратора в группах и в канале для логирования.
-   Все команды модерации проверяют, является ли использующий их администратором чата.
-   Бот не может применять действия к другим администраторам или к самому себе.
-   Большинство команд модерации предназначены для использования в группах и супергруппах.
